# Rivals App
Rivals Guide is an Android application designed to serve as a companion app for players, providing game news, character guides, and personalized user profiles. The app helps players stay updated and access strategies conveniently from their mobile devices.

# 🛠️ Technologies Used
Mobile Application
- Kotlin
- Java
- XML (for UI design)

Backend & Database
- PHP
- MySQL

Tools & Platforms
- Android Studio
- VS Code
- Git & GitHub

# 🎯 Project Objectives
- To develop an Android application that delivers game news and updates to players.
- To implement a character guide section linking to external resources, providing easy access to tips and strategies.
- To create a personalized profile system using explicit intents and data passing for an improved user experience.
